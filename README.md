# Wahala Game Frontend

Baseline scaffold for the `wahala-game` client using React + Vite + TypeScript.

## Stack

- React + TypeScript (strict mode)
- Vite
- React Router
- TanStack Query
- Zustand
- Axios
- Socket.io client
- React Hook Form
- Tailwind CSS
- Vitest + React Testing Library

## Commands

- `npm run dev` - start local development server
- `npm run build` - typecheck and production build
- `npm run test` - run tests
- `npm run lint` - run ESLint

## Environment Variables

Copy `.env.example` to `.env` and update values:

- `VITE_API_URL`
- `VITE_WS_URL`
- `VITE_APP_ENV`

## Project Layout

Core structure follows `WAHALA_FRONTEND.md`:

- `src/components`
- `src/features`
- `src/hooks`
- `src/lib`
- `src/pages`
- `src/services`
- `src/store`
- `src/styles`
- `src/types`
